The labelled product

An object of 𝒜 of size k, an object of ℬ of size m, and the C(n,k) objects of 𝒜 ⋆ ℬ they produce, n = k+m.

object β ∈ ℬ
the rule

The pair (α, β) does not have labels 1,…,n; it has 1,…,k twice. The labelled product fixes this by choosing which k of the labels 1,…,n go to α and relabelling each object in increasing order, so that the relative order inside α and inside β is kept. One choice of subset, one object of 𝒜 ⋆ ℬ.

summing over k: the binomial convolution

Now let 𝒜 and ℬ be whole classes. Every object of 𝒜 ⋆ ℬ of size n comes from exactly one triple (k-subset, α of size k, β of size n−k), so cn = Σk C(n,k) ak bn−k, which is cn/n! = Σk (ak/k!)(bn−k/(n−k)!): the Cauchy product of the exponential generating functions. The table uses the classes chosen above (sequences: k!, cycles: (k−1)!, sets: 1, rooted trees: kk−1).

Made for Math 372: Combinatorics, Reed College, fall 2026 (Flajolet–Sedgewick §II.1–II.2). The unlabelled product 𝒜 × ℬ would give one object from the pair (α, β); the labelled product gives C(n,k), and that factor is why labelled classes use zn/n!.
